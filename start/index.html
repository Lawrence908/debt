Updating this

The page holds no numbers. Everything renders from /data/*.json, so an update is a change to a data file and a reload — no editing of prose.

Each value carries value, as_of, source, source_url and confidence. Keep all five. A figure without a date is a figure you cannot check later.

data/meta.json lists the update cadence per file and the API endpoints for the series that can be automated. Treasury and FRED can run unattended on a cron. StatCan needs vector IDs. The AI capital figures cannot be automated — they come out of filings, ratings notes and press reporting, and need something that can read.

Serve it over HTTP. Opening index.html from the filesystem will fail the fetch calls on CORS.
